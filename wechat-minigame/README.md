# 财神烧香 - 微信小游戏版本

## 项目简介
这是一个基于微信小游戏平台的财神烧香祈福游戏，玩家可以通过烧香祈福，分享获得更多香火。

## 转换说明
本项目是从原HTML5版本转换而来的微信小游戏版本，主要做了以下适配：

1. **移除PHP后端**：将PHP逻辑转换为前端JavaScript
2. **适配微信API**：使用微信小游戏API替代微信JSSDK
3. **调整项目结构**：符合微信小游戏目录规范
4. **适配Canvas渲染**：保持Phaser.js引擎但适配微信小游戏环境

## 项目结构
```
wechat-minigame/
├── game.js              # 游戏入口文件
├── game.json            # 游戏配置文件
├── app.json             # 应用配置文件
├── sitemap.json         # 站点地图配置
├── js/                  # JavaScript文件目录
│   ├── adapter.js       # 微信小游戏适配器
│   ├── loading-scene.js # 加载场景
│   └── main-scene.js    # 主游戏场景
├── images/              # 图片资源目录
└── audio/               # 音频资源目录
```

## 开发环境要求
1. 微信开发者工具
2. 微信小程序账号（用于测试和发布）

## 本地运行步骤
1. 下载并安装微信开发者工具
2. 使用微信开发者工具打开wechat-minigame目录
3. 配置AppID（可以使用测试号）
4. 点击编译运行

## 功能特点
1. **烧香祈福**：点击按钮进行烧香操作
2. **香火系统**：记录可用香的数量，每次烧香会消耗一根
3. **音效系统**：包含烧香音效、背景音乐和金币掉落音效
4. **分享功能**：支持分享到微信，分享后可获得更多香火
5. **二维码关注**：显示二维码引导用户关注公众号，关注后可获得香火奖励
6. **动画效果**：烧香时有烟雾动画效果，增加视觉体验

## 注意事项
1. 微信小游戏对资源大小有限制，请确保总资源不超过20MB
2. 首次加载资源较多，建议使用分包加载优化性能
3. 真机测试时注意音频播放可能需要用户交互触发
4. 分享功能需要在真机环境下测试
